# AI Academic Chatbot Using NLP and ANN 🤖

An Artificial Intelligence-based Academic Chatbot developed using **Natural Language Processing (NLP)** and **Artificial Neural Networks (ANN)** to assist students by providing quick and accurate responses to academic-related queries.

The chatbot understands user questions, processes natural language input, and predicts the appropriate response using a trained neural network model.

---

## 📌 Project Overview

Students often need quick access to information related to:

- Academic courses
- Subjects
- College facilities
- Timetables
- Exams
- Assignments
- Department information
- General academic queries

This project aims to provide an intelligent chatbot system that can interact with students in a conversational manner and reduce the dependency on manual query handling.

# 🧠 Working Methodology

### 1. Data Collection

Academic-related questions and answers are collected and stored in a structured dataset.

### 2. Text Preprocessing

User input is processed using NLP techniques:

- Tokenization
- Lowercasing
- Removing unnecessary words
- Lemmatization/Stemming

### 3. Feature Extraction

The processed text is converted into numerical features that can be understood by the neural network.

### 4. ANN Model Training

The Artificial Neural Network learns patterns from training data and classifies user queries into predefined intents.

### 5. Response Generation

Based on the predicted intent, the chatbot provides the most relevant response.

# ⚙️ Installation and Setup

## Clone the Repository

```bash
git clone https://github.com/kumarraju710/AI-Academic-Chatbot-Project.git
```

## Navigate into Project Directory

```bash
cd AI-Academic-Chatbot-Project
```

## Create Virtual Environment

```bash
python -m venv venv
```

## Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python app.py
```

Open in browser:

```
http://127.0.0.1:8000/
```
